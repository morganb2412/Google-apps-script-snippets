# Demo script

This preview is an explicitly labeled credential-free demo. It performs no external Apps Script or GitHub writes.

1. Open an Apps Script project and point out automatic project detection.
2. Use the embedded **Project**, **Changes**, and **AI Engineer** toolbar actions.
3. In **Repository**, choose **Create & Connect Demo Repository**.
4. Create `feature/approval-workflow`, commit the changes, and create the demo pull request.
5. In **Changes**, show the modified Apps Script file, remotely added README, conflict state, unified diff, and approval warning.
6. In **AI Engineer**, run PLAN for the prefilled Finance approval request, then REVIEW.
7. In **Standards**, show the security and approval rules.
8. In **Health**, show readiness and remaining repository/synchronization state.

Say clearly: “This demo uses the same typed service boundaries planned for Google and GitHub adapters, but external OAuth and writes are disabled in this preview.”
